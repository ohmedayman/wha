## 💼 كيف يسير نظام العمل والبيع خطوة بخطوة؟

### 1. إرسال البرنامج للعميل
- خذ مجلد `dist\واتساب جماعي-win32-x64` واضغطه في ملف ZIP أو سلمه للمشتري.
- العميل يقوم بفك الضغط وتشغيل `واتساب جماعي.exe`.

### 2. خطوة التفعيل
1. عند فتح البرنامج لدى العميل، يظهر له زر **"🔑 كود التفعيل"**.
2. العميل يضغط على الزر، وينسخ **بصمة جهازه الفريدة (HWID)** ويرسلها لك.
3. تفتح أنت ملف [`2_توليد_كود_تفعيل.bat`](file:///f:/%D9%88%D8%A7%D8%AA%D8%B3%D8%A7%D8%A8/2_%D8%AA%D9%88%D9%84%D9%8A%D8%AF_%D9%83%D9%88%D8%AF_%D8%AA%D9%81%D8%B9%D9%8A%D9%84.bat) في جهازك، وتلصق بصمة جهازه وتحدد الباقة (شهرية / سنوية / مدى الحياة).
4. يظهر لك كود التفعيل المخصص لجهازه، تنسخه وترسله له.
5. العميل يلصق الكود ويضغط "تفعيل"، فيعمل البرنامج معه فوراً.

### 3. تشغيل الحملات واستخراج الأرقام
- **ربط واتساب**: مسح رمز الـ QR الذي يظهر في البرنامج من تطبيق واتساب بالهاتف.
- **إضافة الأرقام**: يدويًا، أو لصق قائمة أرقام، أو استيراد ملف CSV، أو **سحب أعضاء جروبات واتساب بنقرة واحدة**.
- **إرسال الحملة**: كتابة الرسالة (مع دعم Spintax والمتغيرات مثل `{name}`)، إرفاق صور أو ملفات، وضبط الفواصل الزمنية الآمنة ثم بدء الحملة مع متابعة التقدم الحي وإمكانية الإيقاف المؤقت أو الإلغاء.
